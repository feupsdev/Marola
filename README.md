### Marola

**Gestão financeira · Protótipo**

Plataforma de gestão financeira para micro e pequenas empresas, com foco na organização do fluxo de caixa e controle de movimentações via Pix. Possui interface responsiva, apresentação de funcionalidades, planos e páginas de autenticação.

**Tecnologias:** HTML5, CSS3, JavaScript e Tailwind CSS.

**Status:** Protótipo demonstrativo.
